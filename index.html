Specializations

  • Manual review of Solidity and Rust contracts — access control, reentrancy, logic flaws, economic exploits, state-machine invariants, and storage collision analysis.
  • Lending, borrowing, liquidation, and accounting flows. Identifying bad-debt scenarios, health factor edge cases, collateral mismanagement, and unsafe state transitions.
  • Staleness checks, manipulation resistance, fallback logic, and TWAP configuration. Understanding how price data breaks downstream accounting and creates insolvency vectors.
  • Message verification, relay trust assumptions, share-value conservation across chains, and state synchronization risks in cross-chain vault and bridge architectures.
  • Deep understanding of the Ethereum Virtual Machine — storage layout, gas optimizations, delegatecall patterns, proxy upgradability, and low-level assembly review.
  • Program-level security on Solana — account validation, PDA derivation, CPI safety, and Anchor framework patterns. Active in Solana-focused bug bounty programs.
  • I’ll follow state and message flow across the network, execution environment, bridge, and settlement boundary rather than treating each component in isolation. Review surfaces: state transitions, validation logic, sequencing, and settlement assumptions; messaging, bridge paths, replay protection, and finality boundaries; precompiles, resource limits, malformed inputs, and denial-of-service surfaces.
  • I’ll use manual review alongside automated techniques when the repository, test harnesses, and threat model support them. These methods supplement review; they do not replace understanding the system. Review surfaces: security invariants, property tests, and stateful behavior; static-analysis findings, fuzzing targets, harness quality, and input boundaries; formal or invariant reasoning for security-critical transitions and verifier logic.
